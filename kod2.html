Код для нового файла «Себестоимость»

  1. Нажмите зелёную кнопку — появится «✅ Скопировано».
  2. Apps Script → слева «+» рядом с «Файлы» → Скрипт → назовите Себестоимость. Файл должен быть последним в списке (ниже «Коридор»).
  3. Удалите в новом файле всё, что там написано, и вставьте код (Cmd+V / «Вставить»).
  4. Сохранить (💾). Ошибок быть не должно.
  5. Начать развертывание → Управление развертываниями → ✏ → Новая версия → Развернуть.
  6. Откройте приложение «Себестоимость» и придумайте ПИН владельца.
