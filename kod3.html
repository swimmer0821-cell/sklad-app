Код для нового файла «Уведомления»

  1. Нажмите зелёную кнопку — появится «✅ Скопировано».
  2. Apps Script → слева «+» рядом с «Файлы» → Скрипт → назовите Уведомления.
  3. В новом файле нажмите в код → Cmd+A (или «Выбрать все») → Cmd+V / «Вставить». Заготовка function myFunction() { } должна исчезнуть полностью.
  4. Сохранить (💾). Ошибок быть не должно. Развертывать не нужно — уведомления работают по таймеру.
